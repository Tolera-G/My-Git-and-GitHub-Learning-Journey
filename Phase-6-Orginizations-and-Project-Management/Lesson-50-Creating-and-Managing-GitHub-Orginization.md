# Lesson 50: Creating and Managing GitHub Organizations

## Overview

A GitHub Organization is a shared workspace for managing repositories, members, teams, and collaborative software development projects.

In this lesson, we learned how to create and configure an organization.

## Learning Objectives

- Create a GitHub Organization.
- Understand organization ownership.
- Navigate the organization dashboard.
- Configure organization profile settings.
- Create repositories under an organization.
- Explore organization security settings.

## Creating an Organization

1. Log in to GitHub.
2. Navigate to https://github.com/account/organizations.
3. Select the option to create an organization.
4. Choose an available organization plan.
5. Enter the required organization information.
6. Complete the creation process.

## Managing an Organization

An organization dashboard provides several management sections:

| Section | Purpose |
|---|---|
| Overview | Organization information |
| Repositories | Project repositories |
| People | Organization members |
| Teams | Groups of developers |
| Projects | Project management |
| Settings | Organization configuration |

## Organization Profile

Important profile information includes:

- Display name
- Description
- Website
- Location
- Profile picture

## Organization Ownership

The creator becomes an organization owner.

Owners have administrative permissions to manage members, repositories, teams, and organization settings.

An organization can have multiple owners.

## Creating an Organization Repository

1. Open the organization.
2. Navigate to Repositories.
3. Select New repository.
4. Enter a repository name.
5. Configure visibility.
6. Initialize with a README if necessary.
7. Create the repository.

## Practical Exercise

1. Create a practice GitHub Organization.
2. Explore its dashboard.
3. Configure its profile information.
4. Explore security and member settings.
5. Create a repository named `organization-practice`.
6. Verify that the repository belongs to your organization.

## Key Takeaways

- Organizations provide centralized project management.
- Organization owners manage administrative settings.
- Organizations can contain multiple repositories.
- Repositories can belong to personal accounts or organizations.
- Security and permission settings help protect collaborative projects.
